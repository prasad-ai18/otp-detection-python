# OTP Detection System

This project detects OTP codes from text messages using Python and regular expressions.

## Features
- Detect OTP from a message
- Detect OTP from multiple messages
- Validate OTP format
- Store OTP detection history
- Menu based interface

## Technologies Used
Python
Regular Expressions (re module)

## Run the program

python main.py
